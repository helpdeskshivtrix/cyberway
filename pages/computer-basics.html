Computer basics

How a computer and the internet work, in plain words.

What you will learn

Hardware and software

Hardware is the physical part: the processor (CPU) does calculations, memory (RAM) holds what is running now, and storage keeps files when the power is off. Software is the instructions that run on that hardware.

The operating system

The operating system (OS), such as Windows, Android, or Linux, shares the hardware between programs, controls who may open which file, and provides the login screen. Many attacks aim at the OS or at programs running on it.

Opening a website

Your browser asks a DNS server for the website's IP address, connects to that address, and requests the page over HTTP or HTTPS. The server replies with HTML, which your browser draws.

Key terms

  • CPU: The chip that runs instructions.
  • RAM: Fast, temporary memory.
  • DNS: The internet's phone book for names.

Try it yourself

  1. Open your computer's Task Manager (Windows) or System Monitor and find how much RAM is in use.
  2. Write down three programs currently running.
  3. Look up your browser's version in its About page.

Practise only on devices and systems you own or have permission to use.
