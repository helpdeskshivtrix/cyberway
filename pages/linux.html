Linux

Command-line basics you will use in almost every security job.

What you will learn

  • Move around the file system
  • Read file permissions
  • Search text with grep

Finding your way

pwd shows where you are, ls lists files, and cd moves you into a folder. Paths starting with / are absolute; cd .. goes up one level.

Permissions

ls -l shows a string like -rwxr-xr--. The three groups are owner, group, and everyone else, and r, w, x mean read, write, execute. chmod changes them. A file writable by everyone is a common security mistake.

Searching

grep "failed" auth.log prints lines containing "failed". Combine commands with a pipe: cat auth.log | grep failed | wc -l counts them.

Key terms

  • Shell: The program that reads your commands.
  • Root: The all-powerful administrator account.
  • Pipe: The | symbol that sends one command's output into another.

Try it yourself

  1. Open a terminal and run pwd, then ls.
  2. Create a folder with mkdir practice and move into it.
  3. Create a file with touch a.txt and run ls -l.

Practise only on devices and systems you own or have permission to use.
