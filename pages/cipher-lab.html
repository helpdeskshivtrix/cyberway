Cipher lab

Classical ciphers, shown step by step. Everything runs in your browser — nothing is sent anywhere.

Caesar cipher

Shifts each letter by a fixed amount. Try brute-forcing all 26 shifts to break it without knowing the key.








Vigenère cipher


Uses a repeating keyword so each letter shifts by a different amount, defeating simple frequency analysis.





 









XOR cipher


XORs each byte with a repeating key. The same operation both encrypts and decrypts. Output shown as hex.
