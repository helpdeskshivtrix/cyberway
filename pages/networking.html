Networking

Addresses, ports, and protocols that let devices talk.

What you will learn

  • Explain IP addresses and subnets
  • Describe what a port is
  • Tell TCP and UDP apart

IP addresses

Every device on a network has an IP address. IPv4 uses four numbers from 0 to 255, like 192.168.1.20. Home networks use private ranges such as 192.168.x.x, which are not reachable directly from the internet.

Ports

An IP address finds the device; a port finds the program. Web servers listen on port 80 (HTTP) and 443 (HTTPS). Open ports that you do not need are extra doors an attacker can try.

TCP and UDP

TCP sets up a connection and re-sends lost data, so it suits web pages and email. UDP just sends, which is faster and suits video calls and games.

Subnets and CIDR

The /24 in 192.168.1.0/24 means the first 24 bits identify the network, leaving 8 bits (254 usable hosts) for devices. Try the Subnet calculator to see this.

Key terms

  • Port: A numbered doorway on a device.
  • CIDR: Notation such as /24 describing network size.
  • Router: Device that forwards traffic between networks.

Try it yourself

  1. Find your private IP address (ipconfig or ip addr).
  2. Use the Subnet calculator on that address with /24.
  3. Work out how many hosts a /26 network allows.
